# Expediente UAP (dashboard web)
Un solo `index.html` con todo incrustado (datos, d3, mapa e imágenes). Funciona con doble clic y en GitHub Pages.
La carpeta `data/` trae los CSV de origen para que quede el respaldo en el repositorio.

## Publicar en GitHub Pages
1. Crea un repositorio en github.com (por ejemplo `uap-dashboard`) y sube `index.html`, `data/` y este README.
2. Settings → Pages → Source: "Deploy from a branch" → Branch `main` / carpeta `/ (root)` → Save.
3. En 1 o 2 minutos queda en `https://TU_USUARIO.github.io/uap-dashboard/`.
